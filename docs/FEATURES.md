# Feature set

One image per feature in the README's **What it does** list, captured on **1.0.6**,
light theme. The six-screen set is in [SCREENSHOTS.md](SCREENSHOTS.md).

| Feature | Image | What it shows |
|---|---|---|
| Ratings on demand | `docs/feature-ratings.png` | The Bear, 8.5 (328k), episode, plot and cast |
| Watch These | `docs/feature-watch-these.png` | service rail and Netflix picks, two panes |
| Continue watching | `docs/feature-continue-watching.png` | Mobland at 71%, 27:30 / 38:33 |
| Instant switching | `docs/feature-instant-switching.png` | two rows, RESUME on each |
| Bookmarks | `docs/feature-bookmarks.png` | a saved 0:37 pill and its delete |
| Stats | `docs/feature-stats.png` | watched, average, strong and awful |

The Ratings and Continue watching images are row crops; the other four are full
1920×1080 screens. Same capture rules as [SCREENSHOTS.md](SCREENSHOTS.md): light theme,
JioHotstar splash background, no OMDb key in frame.

Watch These uses its own two-pane capture (`feature-watch-these.png`), not the README's
`shot-watch-these.png`.
